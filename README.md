# 百人一首あわせ

読み札の上の句や決まり字を見て、4枚の取り札から下の句の札を選ぶ1日5問のゲームです。小倉百人一首の100首と、どこまで聞けば札が決まるかの「決まり字」が、遊ぶうちに身につきます。知らなくても、ヒントで上の句を全部見ながら遊べます。

- 遊ぶ：<https://satou-aaaaa.github.io/hyakunin-awase/>
- 今日の5問はだれでも同じで1日1回。とことん・練習は何度でも遊べます。時間制限はありません。
- 記録は遊ぶ人のブラウザの中だけに残り、外へは送りません。

## 歌と決まり字の出典

- 歌の本文と読み：Wikisource「小倉百人一首」と、小倉山荘「小倉百人一首」の解説で照らし合わせました（作者の名前の書き方は小倉山荘に合わせています）。
- 決まり字：100首の上の句を読む音で比べて、このゲームで数えています。字数ごとの数（1字7・2字42・3字37・4字6・5字2・6字6）と、かなの最初の字ごとの数（あ16・お7など）は、Wikipedia「決まり字」と競技かるたの札の分け方（[かるたらいふ「取り札一覧」](https://karutalife.sakura.ne.jp/learn/fuda.php)）に合うことを検査で確かめています。44番「あふことの」は「おうことの」と読むので「おほ」の歌と同じ音になり、「あふこ」の3字決まりです。
- 学ぶ範囲：文部科学省 中学校学習指導要領（平成29年告示）国語「伝統的な言語文化」。

競技かるたの公式のルールや段位とは関係ありません。
